# Quantum Digit Analytics Dashboard

Real-time analytical statistical tracking matrix processing stream feeds for synthetic indices.

## System Dependencies
* Node.js runtime environment (v16.x or newer)
* Active Deriv WebSockets endpoint access app registration key

## Local Execution Flow
1. Clone repository to workspace directory.
2. Run installation scripts: `npm install`
3. Configure target credentials within the private `.env` variables layer.
4. Execute runtime automation script sequence: `npm start`
